# Staying Up to Date on Security Trends and Threats (§2.7)

## Why
- Cybersecurity landscape **rapidly evolving**; measures must stay effective vs the most recent threats (cyber, physical, other risks); continuous learning & adaptability required

## Methods (6)
1. **Follow cybersecurity news sources**
2. **Participate in cybersecurity conferences and webinars**
3. **Join cybersecurity communities and groups**
4. **Keep up with cybersecurity reports and research**
5. **Actively participate in security competitions**
6. **Build a network with security professionals**

Learn from experts on latest emerging threats; networking, case studies, innovations, research; webinars = live/recorded presentations, discussions, demos, Q&A

## Communities & groups
Online forums to discuss/understand trends, share knowledge:
- **Wilders Security Forums** — AV/anti-malware, encryption, privacy, mobile security, firewalls, spyware
- **Reddit** — r/cybersecurity (training on certs like CISSP prep) · r/netsec (technical info security) · r/netsecstudents (resource hub)
- **Bleeping Computer Forums** · **Antionline Forums** (internet safety) · **Spiceworks Security Forum** · **Hacklido** (open-source blogging) · **ESET Security Forum** (malware finding & cleaning) · **MalwareTips Forums**
- Collaboration tools: **Slack**, **Discord** — real-time discussions

## Reports & research
Study periodically released reports from reputable vendors/orgs:
- Government agencies + **CERTs**: **US-CERT** (US), **CERT-EU** (EU), **CERT-In** (India) — alerts, advisories, reports
  - CERT-In roles: forecasts/alerts for incidents · emergency measures · advisories, guidelines, whitepapers
- **Cybercrime Magazine** — ground-up research synthesis; bird's-eye view of cybercrime
- **CrowdStrike Global Threat Report** — annual intel brief; adversary tactics; trends + notable themes
- **BlackBerry Global Threat Intelligence Report** — industry-specific threats/challenges
- **Trend Micro** threat report — ransomware actors, top abused vulnerabilities (e.g., LockBit 3.0 first ransomware bug-bounty program)

## Competitions
- Practical avenue to stay on latest threats; simulate real-world scenarios; validate skills; community + networking; learn from others' approaches
- Example: **National Cyber League (NCL) Games**

## Networking
- Follow experts/researchers/orgs on **Twitter, LinkedIn, Reddit** (e.g., Eugene Kaspersky @e_kaspersky, Jay Bavisi, Dark Reading, CISA, Schneier Blog)
- Be respectful/considerate; build trust for lasting professional relationships
